# @rdnr/num2es

## 0.2.0

### Minor Changes

- 1515d1b: Incluye conversión completa de números con soporte para monedas (MXN, USD, EUR y otros códigos ISO 4217), género gramatical, escalas hasta trillones, y casos especiales que otras librerías suelen ignorar. Todo esto sin dependencias externas y con TypeScript completo. Funciona como ESM y CommonJS.
